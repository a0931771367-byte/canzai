# 選卡自動回覆：試算表設定步驟（約 3 分鐘）

試算表已經建好：[罐仔私訊（選卡回覆）](https://docs.google.com/spreadsheets/d/1HeZL_UIN-deg5Z0HacisNrX7HXis2DTeLyy-Oa8wzvI/edit)
粉絲的帳號名稱和私訊只會存在這份試算表，每天凌晨 3 點自動刪掉 90 天前的資料。

1. **貼程式**：打開試算表 →「擴充功能」→「Apps Script」→ 把原本內容全刪掉，貼上 [試算表_AppsScript.gs](https://raw.githubusercontent.com/a0931771367-byte/canzai/main/程式部/comments/試算表_AppsScript.gs) 的整段 → 存檔。
2. **部署**：右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」→ 執行身分「我」、存取「所有人」→「部署」（跳授權就選你的帳號 →「進階」→「前往（不安全）」→「允許」，這是你自己的程式）。
3. **執行 setup**：上方函式選單選 `setup` →「執行」。試算表會跳出一個視窗，裡面已經寫好要去的網址和兩段要貼的字。
4. **貼到 GitHub**：照視窗開網址，新增兩個 secret（名稱和內容都照視窗抄）。

貼好之後機器人下一輪就會開始跑。

## 平常怎麼用
- 「選卡待回覆」：已經收到罐仔第一則私訊、回了卡片資訊的人。雲端 Claude 每天 12:00、21:00 會在「罐仔回覆草稿」填好草稿。
- 你看過草稿沒問題就勾「核准」，機器人下一輪就會送出，「送出狀態」會寫上時間。
- IG 規定收到訊息 24 小時內才能回，超過的會標「過期」。
- 「私訊待處理」：其他私訊，要回的話一樣填草稿、勾核准。
