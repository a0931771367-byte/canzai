# 選卡自動回覆：試算表設定步驟（約 5 分鐘）

試算表已經建好：[罐仔私訊（選卡回覆）](https://docs.google.com/spreadsheets/d/1HeZL_UIN-deg5Z0HacisNrX7HXis2DTeLyy-Oa8wzvI/edit)
粉絲的帳號名稱和私訊只會存在這份試算表，每天凌晨 3 點自動刪掉 90 天前的資料。

## 1. 貼程式
1. 打開試算表 → 上方選單「擴充功能」→「Apps Script」
2. 把編輯區裡原本的內容全部刪掉，貼上 `程式部/comments/試算表_AppsScript.gs` 的整段內容
3. 按存檔（磁碟片圖示）

## 2. 跑一次 setup
1. 上方函式選單選 `setup` → 按「執行」
2. 跳出授權視窗 → 選你的帳號 →「進階」→「前往（不安全）」→「允許」（這是你自己的程式，Google 對沒上架的程式都會這樣提示）
3. 回到試算表，會跳出一串很長的英數字 → 複製起來

## 3. 部署成網址
1. Apps Script 右上「部署」→「新增部署作業」→ 齒輪選「網頁應用程式」
2. 執行身分：**我**；誰可以存取：**所有人**（沒有那串密鑰的人呼叫也會被擋）
3. 按「部署」→ 複製「網頁應用程式網址」（https://script.google.com/macros/s/…/exec）

## 4. 貼到 GitHub
repo → Settings → Secrets and variables → Actions → New repository secret，新增兩個：
- `CANZAI_BOT_KEY`：第 2 步那串英數字
- `CANZAI_SHEET_URL`：第 3 步的網址

貼好之後機器人下一輪就會開始跑。CANZAI_STATE_KEY 不需要了，有加的話可以刪掉。

## 平常怎麼用
- 「選卡待回覆」：已經收到罐仔第一則私訊、回了卡片資訊的人。雲端 Claude 每天 12:00、21:00 會在「罐仔回覆草稿」填好草稿。
- 你看過草稿沒問題就勾「核准」，機器人下一輪就會送出，「送出狀態」會寫上時間。
- IG 規定收到訊息 24 小時內才能回，超過的會標「過期」。
- 「私訊待處理」：其他私訊，要回的話一樣填草稿、勾核准。
