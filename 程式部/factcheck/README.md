# 發文當天自動重查（factcheck）

發文前重新打開官網，確認貼文裡的回饋率、上限、活動日期還是對的。有一點疑慮就擋下不發。不花錢。

## 在流程裡的位置

`ig_publish.py post` 會先跑這一關，資料夾裡一定要有 `貼文.md`：
1. **官網重查**（這支程式）：BLOCK 就停止，並在資料夾寫一份 `查證報告.md`
2. 文案檢查（/ig-human、/ig-caption）
3. 發文

被擋下時，執行發文排程的 Claude 會把 `查證報告.md` 貼到內容部討論串，讓內容部修改；改好後重跑就會放行。
排程（run_schedule.py）每次發文前都會自動跑一次，被擋下就不發，並寫進 待處理.md。

## 內容部的查證欄怎麼寫（才能自動查）

```
## 發文前查證

- [ ] 玉山 Pi 卡海外回饋 ｜來源：https://銀行官網活動頁 ｜必須出現：`3%`、`上限 500 元`、`12/31` ｜到期：2026-12-31
- [ ] 社群部「選卡」自動回覆已設定（沒有網址的項目，確認後改成 [x]）
- 本篇沒有引用特定銀行數字，範例數字已在圖上標示「示意」。
```

posts.json 的 `factcheck` 可以直接寫成上面那一整行字串。

| 欄位 | 說明 |
|---|---|
| 來源 | 官網網址，可放多個（空白隔開），找得到就算 |
| 必須出現 | 每個用反引號包起來。比對時會自動統一全形半形、空白、千分位逗號；日期 `11/1` 也接受「11月1日」「2026/11/01」 |
| 到期 | 活動最後一天，過了就擋下 |

## 什麼情況會擋下

- 官網抓不到（網址失效、網站掛了）
- 「必須出現」的字在官網上找不到（多半是條件改了）
- 活動已到期
- 沒有網址的項目、或「## 發文前提」段落裡的項目還沒打勾
- 安全網：文案提到銀行或平台加上百分比，查證欄卻沒有任何官網網址（文案有標「示意／範例」時改為警告、先放行）
- 貼文.md 沒有「發文前查證」段落

每次抓到的官網內容會存一份快照到 `snapshots/`（含抓取時間），日後有爭議可以拿出來對。

## 執行環境

```bash
python3 factcheck.py 貼文資料夾 [更多資料夾…] --report 報告.md
```
這個雲端環境的網路連不到銀行網站，所以正式執行要放在 **GitHub Actions**（免費，和 IG 自動發文同一個地方）或罐子的電腦上。測試時用本機假網頁驗證過 5 種情況都判斷正確。
需要 JavaScript 才會出現內容的官網，請先 `pip install playwright` 讓程式自動改用瀏覽器抓。


## 雲端抓不到官網時：Mac 快照（2026-11-03）
雲端白名單擋住的官網，改讀罐子 Mac 每天抓好、推到 GitHub 的快照，罐子不用再加白名單。詳見 [mac/README.md](mac/README.md)。快照超過 36 小時一律擋下。
