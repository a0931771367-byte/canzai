# 信用卡年費值不值得？用「淨回饋」算一次就知道

年底常收到年費帳單。要不要繳、要不要剪卡，不用憑感覺，算一個數字就好：**淨回饋**。

## 公式：一年拿到的回饋 − 年費 ＝ 淨回饋

- 淨回饋是正的：這張卡有幫你賺錢。
- 淨回饋是 0 或負的：你是在付錢養這張卡。

再進一步，可以拿它跟「一張免年費、回饋 1% 的卡」比：同樣的消費刷免年費卡能拿多少？年費卡的淨回饋要超過這個數字，才真的值得。

## 示意算一次（虛構數字）

| | 年費卡 | 免年費 1% 卡 |
|---|---|---|
| 一年刷卡 | 200,000 元 | 200,000 元 |
| 一年回饋 | 3,000 元 | 2,000 元 |
| 年費 | 1,800 元 | 0 元 |
| **淨回饋** | **1,200 元** | **2,000 元** |

這個例子裡，年費卡的回饋率看起來比較高，扣掉年費反而少拿 800 元。

## 年費常常可以免：先問這 3 個條件

不同銀行寫法不同，以你的發卡銀行公告為準，常見的有：

1. **刷卡次數或金額門檻**：一年刷滿幾次、或滿多少元免次年年費。
2. **電子帳單、自動扣繳**：有些卡設定後可以免。
3. **打客服詢問**：收到年費帳單時，可以直接問有沒有減免方式。

## 罐仔的判斷順序

1. 先查這張卡今年實際拿到多少回饋（App 或帳單上都有）。
2. 用上面的公式算淨回饋。
3. 淨回饋比免年費卡少 → 先問能不能免年費；不能免就考慮停卡，停卡前把點數用掉。

## 常見問題

**Q：首年免年費的卡，第二年要注意什麼？**
在信用卡官網或帳單上找次年年費的減免條件，在快滿一年前確認自己有沒有達到。

**Q：回饋是點數不是現金，要怎麼算？**
看銀行寫的「1 點折抵多少元」，換成元再算。不能折抵現金、只能換商品的點數，保守一點估。
