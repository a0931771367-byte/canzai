# 03｜3 萬元家電，分期還是一次付清？

- **預定發文**：11/7（六）中午 12 點
- **格式**：輪播圖卡 8 張（1080×1350）
- **欄目**：日常省錢｜大額消費
- **為什麼這週發**：雙11 是一年最多人買大家電的時候

## 腳本／每張內容

1. 【cover】3 萬元家電 分期還是一次付清？ — 算給你看，回饋可能差到 900 元
2. 【text】分期 0 利率 不等於0 成本 — 很多卡分期消費不給回饋，有的還收分期手續費。下單前先查清楚。
3. 【text】先查 1｜這張卡分期 有沒有回饋？ — 在銀行官網的活動說明找「分期」兩個字，常寫在不列入回饋的項目裡。
4. 【text】先查 2｜分期 要不要手續費？ — 0 利率不代表 0 手續費。看清楚是「免息」還是「免息又免手續費」。
5. 【calc】算給你看 — 一次付清 30,000 × 3% 回饋 900 元；分期（不給回饋） 回饋 0 元；差多少 900 元
6. 【calc】等等，還有上限 — 大額消費前，先看上限，可能拆成兩個月、或換一張無上限的卡更划算。 — 30,000 × 3% 900 元；假設每月上限 300 元；實際拿到 300 元
7. 【list】罐仔會這樣選 — 現金夠：一次付清拿回饋／現金不夠：選 0 利率又 0 手續費的分期，接受少拿回饋／金額大：先算上限，再決定刷哪張
8. 【cta】收藏起來 下次買大東西前看 — 也傳給正在看冰箱、洗衣機的家人
