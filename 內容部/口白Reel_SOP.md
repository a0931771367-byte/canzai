# 口白 Reel SOP（2026-11-12 起，之後的 Reel 預設有口白）

> 罐子 2026-11-12：「之後也產出有口白的 Reel」。學習對象：@ryshan_home、@joiichew（分析在 `IG學習實驗室/帳號/`）。

## 0. 紅線
- **不擷取、不重用、不克隆任何真人聲音**，包含學習對象帳號（罐子 2026-11-12 規定）。聲音只來自：合成預設聲，或罐子本人錄音。
- 口白念的數字要跟畫面、文案一致，來源與查證日照舊寫在畫面底部和文案最後。
- 不念「最強、必辦、保證」。

## 2. 腳本怎麼寫（學 ryshan_home 的部分）
1. **一幕一句**，每句 8～20 字，**整支 70～90 字**，成片控制在 20 秒內。理由：每週產文流程依被被數據定 Reel 8～20 秒，口白不能變成拉長片長的藉口；合成聲約每秒 5～6 字，90 字＋每幕 0.6 秒停頓就到 20 秒。
2. 三種固定骨架，選一個：
   - **數據快報**：鉤子數字 → 官方數字 → 對比 → 「對你來說」→ 3 步行動 → 二選一提問。
   - **罐仔真心話（A／B 對話）**：朋友問一句、罐仔回一句，兩個不同合成聲。結尾「優缺點一次看」。
   - **新聞翻譯**：新聞一句 → 「對上班族來說」→ 一個行動。
3. 標題和封面帶**欄目名＋編號**（數據快報 EP.01、罐仔真心話 01），固定星期發（學 joiichew「週五來點小眾紀錄片」）。
4. 口白是「說」的，畫面是「看」的：口白不逐字念畫面，畫面放數字和關鍵字，口白講白話。
5. 數字念成口語（五千九百六十一萬），但不要四捨五入成不同數字。

## 3. 規格寫法
每幕加 `vo`（口白文字），貼文加 `voice`：

```json
"voice": {"engine": "azure", "name": "zh-TW-HsiaoChenNeural", "rate": "+8%"},
"slides": [{"kind": "cover", "dur": 2.5, "title": "...", "vo": "台灣的信用卡，每三張就有一張在睡覺。"}]
```

- `engine: "azure"`：有 `AZURE_SPEECH_KEY`、`AZURE_SPEECH_REGION` 就自動合成。
- `engine: "files"`：用 `內容部/口白/<貼文id>/` 裡已放好的檔（Higgsfield 產出或罐子錄音）；缺檔時產生器會列出每一段該存的檔名。
- 文字沒改就重用快取，不重複花額度。
- 幕長會自動拉長到「口白＋0.6 秒」，`dur` 只是下限。
- 混音：有口白時背景音樂降到 0.10、音效 0.55，整體 -16 LUFS。

## 4. 製作步驟
1. 寫規格（第 2、3 節），跑法務與用語檢查（同研究型 Reel SOP 第 4 步）。
2. `cd 內容部/工具 && node make_posts.js ../規格/X.json ../輸出資料夾`
3. 聽一次：數字念對、沒有怪斷句（合成聲念錯的字，改寫法或加逗號，不要改數字）。
4. 貼文.md 會自動列出每幕的 🎙 口白，文案照舊。
